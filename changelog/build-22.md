# Build 22

- Includes [hwrm-anticheat](https://steamcommunity.com/sharedfiles/filedetails/?id=3831649153), which stops the game running `autoexec.lua` (and `-exec` scripts). It's built in, so don't also load the standalone hwrm-anticheat Workshop item alongside 2.3Test: players with a different mod list can't join each other's games. You'll only need that standalone mod when not using 2.3Test (although they are comptable with eachother, its just a needless step).
